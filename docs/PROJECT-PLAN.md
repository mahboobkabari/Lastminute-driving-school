# Lastminute Driving School Website

## Project objective

Build a premium, trustworthy, mobile-first website for Lastminute Driving School, designed to turn local search visitors into lesson enquiries and bookings while remaining simple to maintain and ready for Vercel deployment.

## Phase plan

### Phase 1, Planning & Structure
- Confirm business facts and source material.
- Define sitemap and route strategy.
- Define reusable component architecture.
- Establish design tokens, typography, colour palette, breakpoints, navigation and CTA hierarchy.
- Define booking form data model and validation requirements.
- Define SEO/content structure and structured-data approach.
- Create the scalable project directory structure and project documentation.

### Phase 2, UI/UX Design
- Design the global shell: announcement/contact bar, navbar and footer.
- Design the homepage conversion journey.
- Design page-level layouts for all core routes.
- Establish responsive states and interaction patterns.
- Add restrained motion, focus states and accessible interaction patterns.

### Phase 3, Website Development
- Implement the Next.js + TypeScript + Tailwind application.
- Build reusable UI primitives and content components.
- Implement all routes and responsive layouts.
- Add navigation, mobile menu and shared metadata.

### Phase 4, Content & Functionality
- Add realistic driving-school content using the supplied business facts and review source.
- Implement course, pricing, instructor, testimonial, FAQ and gallery data.
- Implement the booking form with client-side validation and mock submission fallback.
- Add clear status/error/success states without claiming external delivery unless configured.

### Phase 5, Images & Visual Assets
- Optimise the supplied logo and learner/pass-result photography for web use.
- Build an accessible gallery and responsive image treatments.
- Use replaceable placeholders where a business asset is not available.

### Phase 6, SEO & Performance
- Add page titles, descriptions, canonical strategy and Open Graph metadata.
- Add semantic HTML, accessible labels, alt text and structured data where appropriate.
- Optimise images, fonts, JavaScript and loading behaviour.
- Add sitemap/robots configuration.

### Phase 7, Testing & Quality Check
- Test visual layout at 320, 375, 425, 768, 1024 and 1440+ widths.
- Test navigation, forms, FAQ, CTAs and footer links.
- Run TypeScript checks, linting and production build.
- Fix build/runtime/accessibility issues found during QA.

### Phase 8, Local Preview
- Run the production-ready site locally.
- Provide the actual working preview URL from the environment.
- Iterate on requested review changes before approval.

### Phase 9, Final Vercel Readiness
- Verify production build and configuration.
- Document environment variables and deployment steps.
- Confirm no local-only paths or development-only dependencies remain.

### Phase 10, Final ZIP
- Only after user approval, create a clean project ZIP.
- Exclude node_modules, .next and unnecessary cache/build output.
- Include source, assets, configuration, package metadata and README.
